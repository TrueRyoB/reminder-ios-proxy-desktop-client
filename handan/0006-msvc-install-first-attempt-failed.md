# 0006: MSVC Build Toolsインストール、1回目は実は失敗していた

**日時**: 2026-07-26

## 問題
バックグラウンドタスクは「completed (exit code 0)」と報告されたが、これはPowerShellの
`Start-Process -Wait` 自体の終了コードであり、`vs_installer.exe`本体の終了コードでは
なかった。実際にはコマンドライン引数に誤って `"--wait"` という**存在しない**フラグを
含めてしまい(`-Wait`というPowerShellパラメータと混同)、`vs_installer.exe`は引数解析に
失敗してusageを表示して即座にexit code 87で終了 = **実際には何もインストールされて
いなかった**。

## 教訓
バックグラウンドタスクの「completed」通知だけを見て成功と判断せず、
子プロセス自身の終了コード・ログを必ず確認すること。今回はインストーラーの
ログファイル(`%TEMP%\dd_installer_*.log`)を直接確認して判明した。

## 対応
`--wait`引数を取り除いて正しく再実行する。
