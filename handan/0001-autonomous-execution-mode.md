# 0001: 自律実行モードへの移行

**日時**: 2026-07-26
**タスク**: GUI-1〜(承認済み計画の順次実装)

## 決定
ユーザーがPCから長時間離れるため、以後「タスクiが完了(テスト含む)したら、承認を待たずに
Kanban/TaskListを更新し、即座にタスクi+1へ進む」という運用に切り替える。

## 適用範囲・ガードレール
- 実データ(本番リスト・実リマインダー)への書き込みを伴う検証は、既存の教訓
  (`handan`とは別に `iCloud Reminders Proxy - Notes.md` に記録済み)を踏襲し、
  テスト専用のダミーリマインダーのみで完結させる。既存の実データを書き換えない。
- 各マイルストーン完了時に `cargo build`/`cargo test` 等で検証してから次へ進む。
- 重大な設計判断・トレードオフはこの`handan/`フォルダに都度端的に記録する。
