# 0032: QA-I(アクセシビリティ、優先度低)軽度対応

**日時**: 2026-07-26

## 実施方針
ユーザー自身が「優先度低」と明示した項目のため、最も明確で低コストな
改善1点に絞って対応した。

## 実装内容
フラグトグル(`.reminder-flag`)がプレーンな`<div>` + クリックハンドラで
実装されており、キーボードでは到達も操作もできない状態だった
(Tab移動不可、Enter/Spaceでの活性化不可)。以下を追加:
- `role="button"` / `tabindex="0"` / `aria-label`をマークアップに追加。
- `remindersListEl`に`keydown`リスナーを追加し、フォーカスが
  `.reminder-flag`にある状態でEnter/Spaceキーが押されたら
  `toggleFlag()`を発火するようにした。

## 見送った項目(スコープの明示)
- リマインダー行(`<li data-reminder-id>`、タップで編集Sheetを開く)も
  同様にキーボード到達不可だが、優先度低のため今回は対応しなかった。
- 高コントラスト/文字拡大設定への対応は、実際にWindowsの設定を
  有効にして目視確認する必要があり、視覚QA(タスク#21)の領域と重複するため
  今回は実施しなかった。現状、アプリ独自のCSS(色・余白)はWindows
  高コントラストモードの強制配色に追従する仕組みを持っていない
  (Framework7の既定+独自CSSの固定色に依存)ことを既知の制約として記録する。

## 検証内容
1. `npx tsc --noEmit`(gui/) — 通過。
2. `cargo build -p gui` — 成功。
3. `cargo tauri dev`実行、`Get-Process`で`MainWindowTitle='gui'`かつ
   `Responding: True`を確認(クラッシュしないことのみ)。

キーボード操作の実地確認(Tabでフォーカスが正しく移動し、Enter/Spaceで
トグルされるか)は、視覚的な確認を伴うため視覚QA(タスク#21)に委ねる。
