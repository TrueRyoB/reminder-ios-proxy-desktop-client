# idea

## Principle

ここに記すことは、UI(画面 / 通知)の定義と、それから導かれる機能や構成の細部に閉じています。

つまり、stylesheet関連、特に余白や配色などは、外部を参照する必要があります。
../stylesheet/がそれに該当します。

## 原案 : 最高のリマインドアプリが持つべき価値

### 1. スピード

人の思考や行動意欲を阻害しない立ち上げ速度、投函速度、反映速度が求められます。


### 2. 可用性

オフラインでも利用可能であるべきです。
プッシュ通知が届くべきです。
そして、それらの通知は真にrelevantであるべきです。


### 3. 表現

リマインド内の各タスクカードは、structで沢山の変数を持ち合わせています。
proxy clientである以上、これらをどう解釈して、UXに適用するかは自由です。

ここに創造性の余地が生まれます。

少なくとも、以下の機能は、実用価値が未だに見出されていません。
- コレクション名
- フラグ
- 優先度

また、利用体験の改善に合わせて、「自由記入欄をタスク継承に合わせる」や「メタタグを駆使して、カードを分類する粒度を増やす」など工夫が沢山できます。


### 4. ガードレール

...ただし、これらの体験は、最終的にiOSのクライアントでの体験を著しく変えるべきではありません。

通常のネイティブアプリでは、いつも通りの範疇で使えるような程度であるべきです。
