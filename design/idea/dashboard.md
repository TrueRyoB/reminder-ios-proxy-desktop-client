# Dashboard(確定設計 — Gate 1/2 承認済み 2026-08-01)

user-interaction.md(軸・運用重心)→ expression.md(写像・語彙)から導出された画面設計。
導出過程・検査記録・差し戻し履歴は `design/artist/dashboard.md`(問い台帳・非冗長性・動線・全射・直積・状態表)。
プロトタイプ: `design/draft/dashboard-prototype.html`。

## 原則

- **UI はユーザの問いに答える装置**。画面はライフサイクル(発生/保管/着手/実行/完遂)で発生する問いから逆算され、問いなき面を作らない。
- **運用重心**: 発生 > 着手 > 完遂 > 保管 > 実行。一等地はこの順に配る。
- **壁の禁止**: 全量リストをユーザに押し付けない。内部キューは推薦エンジンであり、描画対象ではない。
- **重要度は存在しない**: `priority` は所要時間(大/中/小)の担体。分数など入力粒度を超える精度は表示しない。

## 画面集合

| 画面 | 内容 | 答える問い |
|---|---|---|
| サイドバー | ダッシュボード+マイリスト(具体リスト)+検索。**スマートリストは全廃** | 導線 / あれどこ? |
| ダッシュボード | モード付き単一面: 待機 ⇄ 編成 ⇄ 実行 ⇄ 完走 | 今何を? / この時間で何を? / 次は? / もう終わり? |
| 具体リスト | `list_id == X` の**生集合**(時点・習慣カードが見える唯一の場所)。並び替え編集モードあり | あれどこ? / 整備 |
| 検索結果 | タイトル・メモ部分一致 ∧ **課題ありフィルタ** | あれどこ? |
| クイック投函行 | ナビ直下インライン。3入口: **やること**(鳴らない)/**リマインド**(その時刻に鳴る)/**イベント**(段階的に鳴る)。アニメなし、Enter確定 | 忘れたくない |
| 編集シート | 全射の受け皿: タイトル/メモ/所要時間(大中小)/日時+終日=締切/区分(通常・時報・習慣)/目的/環境/リスト/分解/削除 | 整備 |
| ログイン/2FA | 現状維持 | 認証 |

## ダッシュボードの4モード

**待機**(既定):
- 残高ヘッダ: 「締切不明N件・今週締切N件」— 数字のみ、リストにしない(保管の禁欲)。
- 締切支配ゾーン: 期限切れ(古い順)→着手中🚩→今日(時刻順)。義務なので常時表示(性質上少数)。
- **次の一手**: ゾーン先頭の1枚を最大の要素として提示(理由・サイズ・出所つき)。「これをやる」→実行 / 完了。
- セッション宣言: 「今から◯分・環境◯◯」→編成へ。可処分時間は入力ポート(将来 Google カレンダーで自動化)。

**編成**(献立コンポーザ):
- 宣言と同時に皿を**自動仮組み**: 義務全部+**締切不明を必ず1枚**+高スコア順に容量まで。全て外せる。
- 候補列: 理由バッジつき(⏳逼迫 / 👔同環境 / 🔗同系統 / 🌱いつでも / ⬆浮上(放置N日))。
- 皿: DnD とクリックで出し入れ・並び替え。容量ゲージは定性ラベル(ゆとり/ちょうど/溢れ気味)。
- 息抜き: 大・中が2連続したら小サイズの挿入を提案(☕)。
- 推薦スコア(内部。表示しない): 逼迫(スラック=残日数÷サイズ重み)+100 / 環境一致+30 / 系統一致+20 / 締切なし+25 / エイジング+min(放置日数,30)。サイズ重み 大60/中25/小10 は計算専用。

**実行**:
- 現在カード(開始で🚩自動点灯)+皿の進行表示。完了 / スキップ(このセッションでは再提案しない)/ 中断。
- 完了→後続キャプチャ: クイック投函行が見出しつきで自動オープン(同リスト既定・スキップ可)。

**完走**: 🎉「おしまい / もう一皿」。

## 状態

- ビュー切替時: スケルトン表示(遷移直後の無反応を解消)。
- 空状態: 義務ゼロ(宣言へ誘導)/ 候補ゼロ / リスト空 / 検索ゼロ、それぞれ文言を持つ。
- 「全完了」と「締切不明のみ残」は残高ヘッダの数字で区別される。
